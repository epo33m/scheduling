Each subdirectory under `agent/skills/<name>/` is a self-contained skill: a `SKILL.md` front-matter document (with `name`/`description`) plus optional companion Markdown files (`tests.md`, `mocking.md`, `LOGIC.md`, `UI.md`, `DEEPENING.md`, `DESIGN-IT-TWICE.md`, `HTML-REPORT.md`, `AGENT-BRIEF.md`, `OUT-OF-SCOPE.md`, `ADR-FORMAT.md`, `GLOSSARY-FORMAT.md`). Every skill ships an `agents/openai.yaml` declaring its `display_name` and `short_description` for the skill registry. Skills are not code; they are prompt-driven playbooks consumed by the parent agent via the Skill tool (e.g. `codebase-design` supplies the shared vocabulary of module/interface/seam/adapter/leverage/locality that `tdd`, `improve-codebase-architecture`, and others reference). Cross-skill orchestration patterns include spawning parallel sub-agents (code-review's Standards vs Spec axes, codebase-design's design-it-twice), delegating to other skills via the Skill tool (implement-spec calls tdd and code-review; improve-codebase-architecture calls domain-modeling and grilling), and using background agents for long-running work (research). The only executable artifact in scope is `diagnosing-bugs/scripts/hitl-loop.template.sh`, a bash template providing `step`/`capture` helpers for human-in-the-loop reproduction loops.
