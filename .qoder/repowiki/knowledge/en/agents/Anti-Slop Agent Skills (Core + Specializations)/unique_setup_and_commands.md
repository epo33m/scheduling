Skills are installed through multiple routes (`npx antislop-ai --update`, `npx skills add miqdadbadjuber/anti-slop`, agent plugin commands such as `claude plugin update antislop@anti-slop`, `codex plugin marketplace upgrade anti-slop`, etc.); mode persistence lives in `%APPDATA%\antislop\settings.json` (Windows) or `~/.config/antislop/settings.json` (Linux/macOS) and is set via `npx antislop-ai --mode during|after|ask`. Contrast checking is invoked as `python3 "${CLAUDE_SKILL_DIR}/contrast-check.py" "#FFFFFF" "#777777"`.
