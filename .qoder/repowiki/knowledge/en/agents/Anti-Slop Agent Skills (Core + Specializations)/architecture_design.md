Each subdirectory is an independent skill package consumed by AI coding agents at session load. The `antislop/` directory is the core filter (`SKILL.md` + `VERSION`) defining the shared mechanism: Two Usage Modes (during/after), the Hard Gate / Purpose-Gate / Quality Locks rule tiers (R-01..R-40), the Craftsmanship Standard (C-1..C-5), the Liveliness Toolkit with ENERGY/RHYTHM/MOTION dials, and the Delivery Gate checklist. Every other skill — `antislop-code`, `antislop-copywriting`, `antislop-human`, `antislop-layoutmobile`, `antislop-ui` — is a specialization that references the core rules by number and never duplicates or renumbers them; they are loaded together with the core and scoped to one concern (comments, prose, human/a11y, responsive layout, visual/UI). `antislop-human` additionally ships executable helpers (`contrast-check.py`, `contrast-mcp.py`) plus reference documents under `references/` (`WCAG.md`, `A11Y-PATTERNS.md`). `antislop-ui` carries its own references (`CORE-WEB-VITALS.md`, `WEB-BASELINE.md`). Dependency direction is strictly inward: specializations depend on the core's R-XX numbering and gate; nothing in the core depends back on any specialization. There is no build system — skills are distributed as plain Markdown files installed via `npx antislop-ai`, `skills add`, or agent plugin doors.
