Four sibling skill directories under `agent/skills/`, each a self-contained leaf with an identical layout: a `SKILL.md` frontmatter + prose defining the `<what-to-do>` / `<supporting-info>` protocol, plus an `agents/openai.yaml` declaring the OpenAI skill interface (`display_name`, `short_description`, `policy.allow_implicit_invocation`). The four skills form a pipeline across two modes — **explore** (writing-fragments: mine raw material without committing structure) and **exploit** (writing-beats: assemble beats in a choose-your-own-adventure loop; writing-shape: grow paragraph-by-paragraph from a fixed pile). `writing-for-agents` is meta: it is not a pipeline stage but the universal reference for how to write any document an agent consumes (skills, AGENTS.md, CLAUDE.md), with `SKILL-MECHANICS.md` as its skill-specific branch covering frontmatter, invocation choice (model-invoked vs user-invoked), and router skills. Dependency direction is one-way: the three pipeline skills share the grounding concept (prerequisites vs introduced concepts) but do not import each other; only `writing-for-agents/SKILL.md` references its own mechanics file via a relative link.
