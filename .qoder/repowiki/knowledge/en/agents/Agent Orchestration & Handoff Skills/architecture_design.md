Each subdirectory under `agent/skills/` is an independent skill package with a uniform layout: a front-matter `SKILL.md` describing the skill's purpose and instructions for the model, plus an `agents/openai.yaml` declaring its runtime interface (`display_name`, `short_description`) and invocation policy (e.g. `allow_implicit_invocation: false`). The `ask-matt` skill acts as the central router over all other skills in this module, defining the main idea→ship flow, on-ramps (triage, diagnosing-bugs, wayfinder), vocabulary primitives (domain-modeling, codebase-design), and phase-boundary decisions documented in `PHASE-BOUNDARIES.md`. Cross-skill handoff is mediated by the `handoff` / `claude-handoff` skills, which produce portable markdown summaries written to `$TMPDIR` (or `%TEMP%` on Windows) so sessions can be transferred across harnesses or directories. The `wizard` skill is distinct from the others: it generates a bash script following a shared library in `template.sh` — authors only fill stages below the `STAGES` marker, while the library provides stage management, cross-platform URL opening, hidden secret entry, idempotent `.env` upserts, and GitHub secret/variable writes via `gh`.
