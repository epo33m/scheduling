- Every skill ships an `agents/openai.yaml` alongside `SKILL.md`, declaring `interface.display_name`, `interface.short_description`, and a `policy.allow_implicit_invocation` flag rather than relying on implicit discovery.
- `SKILL.md` files begin with YAML front-matter containing `name` and `description` fields before the prose body, keeping metadata machine-readable.
- Handoff artifacts are always written to the OS temp directory (`$TMPDIR` / `/tmp` / `%TEMP%`) instead of the workspace, and sensitive data is redacted before saving.
- Wizard scripts generated by the `wizard` skill never edit the library above the `STAGES` marker; authors only add `stage()` calls inside `run_wizard` and set `TOTAL_STAGES` to match.
