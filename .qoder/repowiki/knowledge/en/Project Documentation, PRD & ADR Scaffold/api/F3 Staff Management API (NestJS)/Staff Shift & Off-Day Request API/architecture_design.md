Single NestJS module (`request.module.ts`) wiring `RequestController` to `RequestService`. The controller is the thin HTTP boundary: it applies `@Roles('staff')`, injects `@CurrentEmployee()` into a `SessionEmployee`, validates payloads via `parseOffRequest`/`parseShiftRequest` from `@repo/validators`, and delegates all business logic. `RequestService` owns the domain rules — probation gate (ADR 0003), open-window enforcement (ADR 0002), week membership checks, and Prisma upserts against `offRequest` / `shiftRequest` tables keyed by `(weekId, employeeId)` and `(weekId, employeeId, tanggal)`. Pure helpers live in sibling files: `off-day.ts` restricts leave to Mon–Thu, and `request-window.ts` computes whether a `scheduleWeek.requestDeadline` has passed and which future week is the active target. Time is always UTC; dates are converted to/from midnight-UTC ISO strings via local `toDate`/`toCalendarDate` helpers so server timezone does not affect weekday calculations.
