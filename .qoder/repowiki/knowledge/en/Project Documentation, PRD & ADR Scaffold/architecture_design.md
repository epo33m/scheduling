The module is purely documentary — no runtime code lives here. It anchors three concerns:
- Product scope in `docs/PRD-Aplikasi-Penjadwalan-Shift-Kyne.md`, defining the MVP (Google-authenticated weekly shift planner for 6 bar/kitchen staff plus 1 manager), the seven functional modules (F1–F7), business rules, coverage constraints, and a draft data model.
- Architectural decisions under `docs/adr/` following the ADR-0001 convention; four decisions are recorded so far (monorepo tooling, request-window locking without cron, probation without holidays, weekly cycle anchoring).
- An agent-skill registry under `docs/agents/` (`domain.md`, `issue-tracker.md`, `triage-labels.md`) intended to pin third-party Markdown skills consumed by a `skills-lock.json` manifest and per-skill `agents/openai.yaml` profiles, driving future AI-assisted implementation once the Bun/Turborepo stack and directory layout are chosen.
The README at the repo root is the entry point, pointing readers to the PRD as the source of truth and listing the Bun + Turborepo monorepo layout (`web`, `api`, `packages/types`, `packages/validators`). `.gitignore` excludes env files, build artifacts, Prisma-generated clients, editor state, and `graphify-out/`, reflecting the downstream Bun/Turbo/Prisma toolchain.
