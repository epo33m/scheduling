Children are not linked at runtime — there is no shared library or orchestrator code. Each skill under `agent/skills/<name>/` is an independent unit composed of a prompt-driven `SKILL.md` plus an optional `agents/openai.yaml` that pins model parameters; some skills add supporting assets (`scripts/`, `references/`, domain docs). The `.agents/skills/` sibling tree is the runtime discovery root used by the consuming application to load these skills, kept in sync with the editable source tree so the repo ships both versions. Cross-skill communication goes exclusively through handoff skills (e.g. `handoff/`, `claude-handoff/`) that pass context between separate agent sessions rather than through shared state.
