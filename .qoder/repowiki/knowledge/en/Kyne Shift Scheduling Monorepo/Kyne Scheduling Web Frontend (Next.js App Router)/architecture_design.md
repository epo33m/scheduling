Three layers compose under `web/`: `app/` exposes Next.js App Router routes (login, manager dashboard/draft/staff, staff request/schedule) that call server actions; `lib/` provides the typed NestJS API client (`api.ts`), Supabase session helpers, role/label maps, and route guards consumed by both `app/` pages and the E2E fixtures; `e2e/` runs Playwright against a real hosted Supabase project. The Playwright config boots two web servers in parallel — the NestJS API on port 3211 and the Next.js app on port 3210 — passing `E2E=1` so the login route serves password-based auth headlessly, and `API_URL=http://127.0.0.1:3211` so the API client targets the dev instance. `next-env.d.ts` references generated route types from `.next/dev/types/routes.d.ts`, keeping page imports type-safe across `app/`.
