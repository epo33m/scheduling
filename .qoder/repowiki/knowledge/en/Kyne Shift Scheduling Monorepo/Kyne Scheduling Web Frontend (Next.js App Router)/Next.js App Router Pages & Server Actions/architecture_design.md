Built on Next.js App Router with a flat `web/app/` layout: `layout.tsx` is the root HTML shell (Indonesian locale, global CSS), `page.tsx` is a dynamic router that calls `getMe()` and redirects to `/manager`, `/staff`, or `/login` based on role. Authentication flows live under `auth/`: `callback/route.ts` completes Google PKCE via Supabase and runs `employeeGate` before redirecting, while `auth/e2e-login/route.ts` is an `E2E=1`-gated password-login helper for Playwright. Feature routes are grouped by role — `manager/{dashboard,draft,staff}` and `staff/{request,schedule}` — each page co-locating its UI components, CSS modules, and a sibling `actions.ts`. Mutations go through `'use server'` functions in those action files; they call shared API helpers from `@/lib/api`, validate only what the UI needs, and always `revalidatePath(...)` in a `finally` block so the view snaps back to server truth regardless of success or failure. The module depends outward on `@/lib/*` (api, supabase, employee-gate, safe-next, login-error) but has no intra-module cross-imports between feature folders.
