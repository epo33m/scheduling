The repo is a Bun workspaces + Turborepo monorepo whose top-level `bun run` scripts orchestrate the three runtime children (`web`, `api`, plus shared `packages/types` and `packages/validators`). The web (Next.js App Router) talks only to the NestJS API over HTTP; both share Prisma-generated types from a single Supabase Postgres schema. Cross-child contracts live in `packages/types` (e.g. `SHIFT_TYPE_CATALOG`) and `packages/validators` (Zod schemas reused by api and seed). Database access is gated: RLS deny-all on every table forces all reads/writes through the API, and timezone-local WITA times are stored as `varchar(5)` strings rather than SQL `time` columns so they never drift across sessions. The PRD at `docs/PRD-Aplikasi-Penjadwalan-Shift-Kyne.md` is the authoritative source of truth for domain rules (weekly cycle, request window, coverage), while `docs/adr/` records architectural decisions that constrain how the children evolve.
