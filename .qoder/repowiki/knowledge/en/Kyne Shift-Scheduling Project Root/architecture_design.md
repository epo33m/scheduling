This scope contains no runtime code; it is the project's single source of truth. `docs/PRD-Aplikasi-Penjadwalan-Shift-Kyne.md` defines the MVP (Google-authenticated weekly shift planner for six bar/kitchen staff plus one manager) and the F1–F7 functional modules. `docs/adr/` records implementation decisions using the `NNNN-title.md` convention. `docs/agents/` registers Markdown-based skills (`domain.md`, `issue-tracker.md`, `triage-labels.md`) intended to be consumed via a `skills-lock.json` manifest and per-skill `agents/openai.yaml` profiles once the Bun/Turborepo stack is chosen. The root `README.md` points to the PRD and documents the expected monorepo layout (`web`, `api`, `packages/types`, `packages/validators`), while `.gitignore` reflects the downstream toolchain (Bun workspaces, Prisma generated clients, editor state, `graphify-out/`).
