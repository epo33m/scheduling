Single-file library under `packages/weeks` with a flat layout: `src/index.ts` re-exports everything from `src/weeks.ts`, which is the only source of logic. The package is published as an ESM module (`module: node16`) with dual `main`/`types` entry points pointing at `dist/index.{js,d.ts}`; tests live alongside sources as `*.spec.ts` files excluded from compilation. There are no runtime dependencies — only TypeScript and Vitest as devDependencies — and all date math uses the built-in `Date` constructor plus `Intl.DateTimeFormat` for timezone-aware formatting.
