The app root (`app.module.ts`, `main.ts`) bootstraps NestJS via `bootstrap()` in `main.ts` and registers four feature modules: `AuthModule` (JWT validation + role guards), `EmployeeModule` (manager-only CRUD), `RequestModule` (staff-facing off-day/shift requests), and `HealthModule` (public `/health`). All feature modules share two cross-cutting concerns injected at the root level: `PrismaService` from `prisma/prisma.module.ts` for Postgres access, and `EnvService` from `env.ts` for configuration. Authentication is applied uniformly through `@UseGuards(AuthGuard)` plus `@Roles()` decorators on controllers, so every protected endpoint goes through the same Supabase token → employee whitelist → role check pipeline before reaching business logic.
