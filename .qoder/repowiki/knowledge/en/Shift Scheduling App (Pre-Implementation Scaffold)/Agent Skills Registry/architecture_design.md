Every child skill under `agent/skills/<name>/` follows the same layout: a `SKILL.md` that describes the prompt-driven behavior plus an optional `agents/openai.yaml` that pins the model/parameters for that skill. Some skills also ship supporting assets (`scripts/`, `references/`, domain docs like `GLOSSARY-FORMAT.md`). The `.agents/skills/` sibling directory is the runtime discovery root used by the consuming application to load these skills; the two trees are kept in sync so the repo ships both the editable source and the installed copy. Cross-skill communication happens through handoff skills (e.g. `handoff/`, `claude-handoff/`) that pass context between sessions rather than through shared code — there is no runtime library linking children together.
